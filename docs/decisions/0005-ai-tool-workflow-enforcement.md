## 추정되는 결정

AI 코딩 도구(Claude Code, Cursor, Copilot 등)가 프로젝트 규칙을 따르게 하기 위해 AGENTS.md 체계를
도입하고, 아래를 강제한다고 추정된다.

- 모든 폴더 작업은 해당 폴더(또는 상위)의 AGENTS.md 지침을 따른다.
- AI가 생성한 코드도 사람이 리뷰 없이 병합하지 않는다 (팀장 반영 또는 CODEOWNERS 리뷰, ADR-0006).
- 예시·임시 선언은 구현에 그대로 반영하지 않고 참고만 한다.
