## 1. 배경

코드잇 창업가 과정 2기 3팀, 22일·198시간 동안 5명이 만드는 프리랜서-클라이언트 매칭 플랫폼(PactFive) MVP.

## 2. 결정 — 8개 기능 + 3단계

RFP §3.1~3.7 기준 8개 기능을 MVP 범위로 한다: user-management, project-management, applications,
notifications, engagement, ai-pricing, contracts-payments, reviews.
(§3.2에 포함된 지원 관리(3.2.4)를 applications로 분리 — 지원/수락/거절 흐름이 프로젝트 CRUD와 성격이
달라 별도 담당이 자연스럽기 때문. 근거: ADR-0004 §5)

구현은 3단계로 나눈다.

| Step | 내용 | RFP 대응 |
|---|---|---|
| Step 1 | 8개 기능 필수 요소 | 기본 필수 (RFP §8.1) |
| Step 2 | 심화 기능 | 고급 필수 (RFP §8.2) |
| Step 3 | 비교우위 기능 | 도전 과제 + 자체 차별화 |

우선순위는 Step1 > Step2 > Step3이며, 일정이 밀리면 Step3 → Step2 → Step1 역순으로 자른다.
