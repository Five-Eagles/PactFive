### 아직 확인 못 한 위험

- **납품 업로드 준비 정보가 서버 메모리에만 있음** (`public-api.service.ts` preparedUploads).
  Vercel 서버리스에서 upload-prepare 와 request 가 다른 인스턴스로 가면 납품 요청이 실패할 수 있다. 배포 환경에서 확인 필요.
- **배포 환경 결제 완료**: 개발용 결제 대체 경로는 배포 서버에 없다. 라이브 데모는 Toss Sandbox 결제창을 실제로 거쳐야 하며, 성공 경로는 아직 아무도 확인하지 않았다.
- **OpenAPI 문서와 실제 서버 불일치**: 협상 수락 `expectedRound`, 납품 `size·sha256·objectKey·uploadId`. 문서 정리 때 수정.
