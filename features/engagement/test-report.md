## ux-philosophy.md §6 자체 점검

`design/` 이 있는 기능이라 해당된다. 팀장 통합 게이트의 같은 검증을 **대신하지 않는다.**

**7항목 중 5개 충족 · 2개 미충족.**

| 검증 항목 | 이 화면에서 어떻게 충족하는가 (또는 왜 못 하는가) |
|---|---|
| 상태 이해 | ✅ 북마크 아이콘이 저장/해제 상태를 `aria-pressed` 와 모양으로 함께 보여준다. 목록에서 마감된 항목은 배지와 비활성 버튼 문구(`모집이 마감되었습니다`)로 왜 지원할 수 없는지 알린다. 저장 일시를 카드마다 표시해 "언제 담았는지"를 알 수 있다 |
| 근거 이해 | ⚠️ **부분.** 카드의 예산·마감·지원자 수는 프로젝트 원본 값을 그대로 보여준다. 다만 **추천 프로젝트가 왜 추천됐는지 화면에 없다.** 규칙 28 이 내부 점수·순위값 노출을 금지해서 숫자는 못 내보내는데, "같은 카테고리" 같은 **사유 문구**는 금지 대상이 아닌데도 넣지 않았다 |
| 작업 보호 | ✅ 북마크는 서버에 즉시 저장되고 입력 상태가 없다. 낙관적 반영을 쓰되 **실패하면 이전 상태로 되돌리고 `role="alert"` 로 이유를 알린다**(규칙 31). 마감·취소된 프로젝트를 자동으로 지우지 않아, 사용자가 담아둔 것이 임의로 사라지지 않는다(규칙 8·13) |
| 복구 가능성 | ✅ 빈 목록은 오류가 아니다. `저장한 프로젝트가 없습니다` + `프로젝트 둘러보기` 로 다음 행동을 준다(규칙 15). 없는 것을 지워도 오류가 아니라 성공으로 처리해(규칙 2) 재시도가 막히지 않는다. 비로그인이 북마크를 누르면 로그인으로 안내하고 원래 프로젝트로 돌아온다 |
| 선택권 | ⚠️ **부분.** 담기·해제를 사용자가 결정하고, 해제한 것을 다시 담을 수 있다. 다만 **추천을 거절하거나 접는 경로가 없다.** 규칙 24 는 후보가 0건일 때만 섹션을 감추므로, 사용자가 원하지 않아도 항상 4건이 붙는다 |
| 비파괴성 | ✅ 북마크 해제는 되돌릴 수 없는 행동이 아니다 — 같은 버튼을 다시 누르면 복원된다. 규칙 4 가 행을 실제로 지우지만 사용자 기준으로는 손실이 아니라서 확인 단계를 두지 않았다. **이 기능에는 파괴적 행동이 없다** |
| 접근 가능성 | ✅ 북마크 버튼에 `aria-pressed` 와 상태별 `aria-label`(저장/해제)을 준다. 실패 안내는 `role="alert"`. 빈 상태는 `role="status"`. 상태를 색으로만 구분하지 않는다 — 아이콘 모양(☆/★)과 배지 글자가 함께 바뀐다. **화면 확대·보조 기술 실측은 아직 안 했다** |

### 미충족 2건을 어떻게 처리할 것인가

| | 무엇 | 규모 |
|---|---|---|
| 근거 이해 | 추천 카드에 `같은 카테고리` · `기술 2개 일치` 같은 **사유 문구** 추가. 점수·순위값이 아니라 규칙 20 의 우선순위 근거를 말로 쓰는 것이라 규칙 28 에 걸리지 않는다 | 카드 1줄 |
| 선택권 | 추천 섹션 접기 | 규칙 24 와 어긋날 수 있어 **판단이 필요하다** |

**선택권 쪽은 혼자 정할 수 없다.** 규칙 24 는 "후보 0건이면 감춘다"만 정했고 사용자가 접는 경우는 다루지 않았다. 접기를 넣으면 규칙을 늘려야 한다.

## 아직 안 되는 것 (Known Issues)

- **`prototype/server/` 는 구현 초안이다.** 실제 DB 없이 `mock/` 위에서 돈다.
- **`ProjectReadPort` 3종이 project-management 에 아직 없다** (CR-0001).
  Mock 어댑터가 대신하고 있고, 실제 구현이 올라오면 어댑터 한 곳만 교체한다.
- **`web/ui.tsx` 가 project-management 것과 거의 같다.** 기능 폴더 간 직접 import 가
  금지돼 있어(2026-08-28 팀 표준) 두 벌을 따로 뒀다. **통합 단계에서 `app/web/src/shared/`
  로 뺄 후보다** — 지금 한쪽만 고쳐지는 것보다 중복이 안전하다.
- **페이지네이션 UI 가 없다.** 서버는 페이지를 나눠 주지만 화면에 페이지 버튼이 없다.
