## 지킨 것

**원시 색상값은 `_tokens.css` 의 `:root` 에만 있다.** 화면 3장 본문은 0개다.
`npm run check:design` 통과.

값은 `design-system/design-tokens.md` 정본을 그대로 옮겼다. 변환본이 쓰던
`teal #007a80` · `yellow #ffd735` 는 정본(`#008A8D` · `#F4C430`)과 달라 되돌렸다.

`design-tokens.md` §12 금지 패턴을 따랐다.

- 목적 없는 그라데이션·다색 카드 없음
- 그림자는 두 단계뿐 (`--shadow-card` · `--shadow-raise`)
- 캠페인 색(노랑·자주)은 **기획전 배너 안에서만**
- 반경을 `sm`·`md`·`lg` 로 나눠 모든 영역을 같은 카드로 감싸지 않음
- 마감·손실을 과장하는 문구 없음

썸네일은 사진 대신 **작업물 형태를 그린 SVG** 다. 대시보드·표·브랜드 가이드처럼
실제 결과물로 읽히게 했다. 의미 없는 회색 블록을 두지 않으려는 것이고,
실제 이미지가 준비되면 그 자리에 넣으면 된다.

## 바꾼 것 — 확인이 필요하다

**카테고리를 10종에서 6종으로 줄였다.** PNG 시안의 10종(브랜딩·영상·사진·콘텐츠 등)은
ERD `projects.category` 에 없는 값이다. 그대로 두면 누를 수 없는 메뉴가 된다.
카테고리를 늘릴지, 화면을 6종으로 둘지 정해야 한다.

**필터를 버튼이 아니라 상시 패널로 뒀다** (`browse.html`).
시안의 `필터` 버튼은 열릴 화면이 정의돼 있지 않다 (feedback_loop 2026-08-28 항목 6).
패널로 두면 무엇으로 거를 수 있는지가 항상 보이고, 별도 화면을 설계하지 않아도 된다.

## 하지 않은 것

- 실제 사진·로고 없음. SVG 삽화로 대신했다
- 로그인·프로필·전문가 찾기 화면 없음 — 오민혁 담당이다
- 모션 규칙 미적용. `reference-snapshot.html` 에 정리된 것을 나중에 얹으면 된다
