# design-system — 작업 지침

이 폴더의 산출물을 만드는 방법은 `sdd-framework/templates/design-system-guide-template.md`를
따른다 (TS 토큰·타입 정의 + 인터랙티브 HTML 프리뷰 2종 필수).

- `design-tokens.md`: TS 토큰·타입 정의 원본
- `design-system-preview.html`: 팀원이 확인하는 인터랙티브 프리뷰

이 폴더가 확정되면 `features/{기능}/design/`의 시안이 low-fi → high-fi로 전환된다
(`sdd-framework/feature-workflow.md` 참고).
